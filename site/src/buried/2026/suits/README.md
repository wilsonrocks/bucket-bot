# Fate Deck suit placeholders

Placeholder suit icons until the real Malifaux suit artwork is in. Drop a
replacement SVG in with the same file name to swap one; the site
(`site/src/buried/2026/suits/`) and the share images
(`backend/logic/buried/2026/suits/`) each keep a copy, so update both.

| file      | suit       | placeholder               |
|-----------|------------|---------------------------|
| ram.svg   | Rams       | Twemoji 1f40f ram         |
| crow.svg  | Crows      | Twemoji 1f426-200d-2b1b black bird |
| mask.svg  | Masks      | Twemoji 1f3ad performing arts |
| tome.svg  | Tomes      | Twemoji 1f4d6 open book   |

Twemoji graphics © Twitter, Inc. and other contributors, licensed under
CC-BY 4.0 (https://creativecommons.org/licenses/by/4.0/), via
https://github.com/jdecked/twemoji.

Jokers have no icon of their own: the Red Joker shows a red J with all four
suits, the Black Joker a black J and no suits.
